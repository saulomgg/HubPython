# 🎥 InstaGram Downloader

This script allows downloading multiple Instagram video links with a simple interface and automatic processing.

The tool supports high-quality downloads and automatic merging of audio and video.

---

## 🚀 Features

- ✔️ Download multiple Instagram videos
- ✔️ High-quality output
- ✔️ Simple GUI interface
- ✔️ Automatic audio and video merging
- ✔️ Direct download via link (no browser required)
