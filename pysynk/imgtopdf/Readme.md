# 🖼️ Image to PDF Converter

## 📌 Sobre

Image to PDF Converter é uma ferramenta simples em Python para converter imagens em arquivos PDF individuais de forma rápida e prática, utilizando uma interface gráfica com Tkinter.

---

## 🚀 Funcionalidades

- ✔️ Adicionar múltiplas imagens (JPG, PNG, JPEG, GIF, BMP, WEBP)
- ✔️ Remover imagens antes da conversão
- ✔️ Selecionar pasta de saída
- ✔️ Conversão mantendo proporção original da imagem
- ✔️ Interface simples e intuitiva
