# 🎥 Bilibili Video Downloader

## 📌 Sobre

Script em Python para download de vídeos do Bilibili com interface simples e intuitiva.

Permite baixar vídeos diretamente através de um link, com suporte a melhor qualidade disponível e processamento automático de áudio e vídeo.

---

## 🚀 Funcionalidades

- ✔️ Download de vídeos do Bilibili em alta qualidade
- ✔️ Interface gráfica simples (GUI)
- ✔️ Junção automática de áudio e vídeo
- ✔️ Download direto via link (sem necessidade de navegador)
